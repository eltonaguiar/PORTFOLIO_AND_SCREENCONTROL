1. Candidate Discovery – “Self‑Deception‑Free” Design
Step	What to Do	Why It Matters	Practical Tips
1.1 Hypothesis Definition	Formulate a clear, non‑parametric “statement of value” (e.g., Price‑to‑Volatility yields >10% excess return).	Avoids ad‑hoc fitting; ensures repeatability.	Write it as a testable equation: return_t = f(var_t) + ε_t.
1.2 Pre‑Registration	Publish the hypothesis, data source, entry rules, exit rules, and pre‑selected evaluation metrics before looking at the data.	Eliminates hindsight bias and data‑mining; satisfies academic rigor.	Use a platform (e.g., Open Science Framework) or institutional repository.
1.3 Out‑of‑Sample “Trial” Window	Run the strategy on a dry‑run period that is excluded from both the discovery and final evaluation (T₀–T₁).	Detects over‑fitting within the discovery window; acts like a “mock‑live” test.	Choose a window that is temporally distant from the final backtest; e.g., 5–10 years before the final test.
1.4 Forward‑Whisker Validation	Perform the same strategy on a new period (T₁–T₂) to see if signals persist.	Spot time‑varying regimes or structural breaks.	Repeat with different calendar months or market cycles.
2. Backtest Construction Rules
Issue	Rule	Implementation
2.1 Point‑in‑Time Data	Use transaction‑level or daily open‑high‑low‑close prices that are contemporaneously available at the decision time.	Store a snapshot of the market at each candle close; never use “future‑looked” tick data.
2.2 Survivorship Bias	Include delisted, bankrupt, and merged securities.	Pull full universe history from a source that records delistings (e.g., CRSP, Datastream).
2.3 Look‑Ahead Bias	Ensure signals are computed only from information available before the decision horizon.	Keep a lag of one period between signal calculation and order placement.
2.4 Transaction Costs	Add realistic bid‑ask spread, commission, overnight financing, and slippage.	Calibrate to historical trading data or use proprietary cost models.
2.5 Corporate Actions	Adjust returns for splits, dividends, spinoffs, and mergers.	Use a corporate actions file to retroactively adjust price series.

Rigorous Methodology for Trading Strategy Validation
1. CANDIDATE DISCOVERY: PRE-REGISTRATION & TRIAL ACCOUNTING
Pre-Registration Protocol
Before touching any data:

Step	Action	Deliverable
1a	Write a specific hypothesis: factor, mechanism, return source, expected Sharpe ≥ X	Dated document with signature or blockchain timestamp
1b	Specify universe: asset class, geography, market cap/liquidity floor, survivorship treatment	Universe definition immutable before backtest
1c	Define signal: exact computation, rebalance frequency, holding period, rank/threshold rule	Python/pseudo-code with mock data
1d	State trading rules: entry/exit, position sizing, leverage, margin, slippage model	Discrete specification, not narrative
1e	Declare ex-ante expected Sharpe, max drawdown, capacity (AUM where α → 0)	Stored in tamper-evident location
1f	List researcher degrees of freedom: all parameter sweeps you plan	e.g., "MA windows 5–250 by 5; breakout threshold ±0.5–3σ"
Example pre-registration (GitHub timestamp or formal registry like OSF):

Strategy: Mean-reversion in SPY via 20-day Bollinger Band squeeze
Universe: SPY only, survivorship bias: N/A (single liquid asset)
Signal: Close < BB_lower(20, 1.8σ) → long; Close > BB_upper(20, 1.8σ) → flatten

Degrees of freedom: will optimize band width [1.5, 2.5] and period [15, 25]
Trial Accounting (Bonferroni-style correction)
If testing N independent parameter sets, apply correction upfront:

Number of Trials (N)	Sharpe × Correction	IR × Correction	p-value threshold
1	1.0×	1.0×	0.05
5	1.4×	1.1×	0.01
10	1.6×	1.2×	0.005
25	1.8×	1.3×	0.002
100	2.1×	1.5×	0.0005
Rule: Sharpe ≥ 1.0 is not acceptable if 10 variants tested; require Sharpe ≥ 1.6 or apply False Discovery Rate (FDR) correction instead.

2. BACKTEST CONSTRUCTION RULES
Critical Data & Methodology Checklist
Issue	Requirement	Violation Cost
Point-in-Time Data	Use only data available at decision time; no lookahead. Fundamental data lagged ≥ 60 days.	++ 0.3–0.8 Sharpe overstated
Survivorship	Include delisted, bankrupt, merged securities from inception (not partial history).	++ 0.4–1.2 Sharpe overstated
Corporate Actions	Adjust prices (splits, dividends, spin-offs) correctly; use adjusted close, not split-adjusted naively.	++ 0.1–0.4 Sharpe overstated
Slippage	Implementation shortfall: 0.5–2 bps per side (varies by asset/volume). Never ignore.	++ 0.1–0.5 annual return
Commissions	Equities: 1–5 bps, futures: $2–$10/contract. Options: include bid–ask, gamma slippage.	++ 0.05–0.3 annual return
Market Impact	For capacity ≥ $100M: scale cost as sqrt(notional/ADV). Model separately.	++ nonlinear cost scaling
Borrowing Cost	Shorts pay borrow rate (varies 50–1000 bps for hard-to-borrow); update dynamically.	++ 0.1–0.8 annual return
FX Conversion	Spot rates at trade time, not close. Hedge costs if relevant.	++ 0.05–0.2 annual return
Dividends	Use ex-date, not payment date. Cash reinvested same day at close.	++ 0.05–0.3 annual return
Gaps & Halts	Trade at next open if stock halted/limit-down at signal. Discard < X% of trials.	++ 0.1–0.3 Sharpe if ignored
